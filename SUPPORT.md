# Support Friends-SNCMS / Projekt unterstützen

[![Support Friends-SNCMS](docs/images/support-ko-fi.svg)](https://ko-fi.com/A0A66XI3A)

Donations are **always voluntary**, support the project and never affect MIT license rights, issue priority, access or maintainer decisions. There is no compulsory subscription or revenue share.

If you operate a business using Friends-SNCMS, earn income from your community, or sell themes/plugins, please consider donating to the free core that supports your work. Donations help sustain development, maintenance and documentation. They do not purchase a guaranteed feature, support contract or security review.

Testing, translations, documentation, code contributions and helping other users also support the project. [Contribution rules](CONTRIBUTING.md).

## Website widget

GitHub Markdown does not run external JavaScript widgets. The repository uses a local linked image plus the GitHub funding button. For an external project website, the supplied Ko-fi widget is:

```html
<script type='text/javascript' src='https://storage.ko-fi.com/cdn/widget/Widget_2.js'></script><script type='text/javascript'>kofiwidget2.init('Support me on Ko-fi', '#72a4f2', 'A0A66XI3A');kofiwidget2.draw();</script>
```

This code is documentation only; it is not injected into CMS installations. The widget contacts Ko-fi when embedded in an external website.
