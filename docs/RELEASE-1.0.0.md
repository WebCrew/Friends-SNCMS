# Friends-SNCMS 1.0.0 — First Final

First public Final release authorized by Andreas Holzer @WebCrew after online installer and interface testing. Based on 0.3.7; existing schema 3 retained. No new feature scope is added for this release.

Includes automatic link cards, configurable upload size/attachment count, community artwork, floating chat, recorded voice messages, a shared six-person microphone room, email verification/recovery and the administration/plugin/theme foundation.

## Download and install

Use Friends-SNCMS-1.0.0-Webspace.zip, extract, upload every file including .htaccess, and open your HTTPS URL. [Installation](INSTALL.md). Back up and preserve private storage for updates. Checksums are distributed with the release.

## Validation limits

The owner tested the online installer and normal interface. Local PHP 8.4 syntax and isolated SQLite suites pass. GitHub CI records actual PHP/JavaScript and MySQL 5.7 smoke-test results separately. Physical microphone/cross-network acceptance and independent security review are not certified. [Validation details](VALIDATION.md).
