# Themes & plugins directory / Erweiterungskatalog

The central directory lives in [GitHub Discussions](https://github.com/WebCrew/Friends-SNCMS/discussions). Use the **Plugins** and **Themes** categories to browse or submit. One discussion per package; maintain the original entry for new versions. Search existing entries before posting. Built-in examples remain in plugins/ and themes/.

## Required listing information

- Unique package ID, author, purpose and original source/repository URL.
- Release/download URL and readable license. State **free**, **paid**, or recurring costs clearly.
- Tested Friends-SNCMS versions, extension API version (currently 1), PHP/database requirements and DE/EN support.
- Installation/removal/recovery instructions, dependencies, requested access and changes to stored data.
- Screenshots with fictional data, changelog, limitations and support/bug-report link.
- Mark unmaintained entries and incompatible versions clearly. Do not claim maintainer approval unless explicitly given.

Free and commercial listings are welcome. No listing fee or donation is required. If you earn money with extensions, please [support the core voluntarily](../SUPPORT.md). Donations never buy an endorsement.

## Safety and moderation

This is a community directory, **not a verified marketplace or automatic updater**. Presence is not a source/security review. Administrators review source and provenance, back up their installation, and install compatible API-1 packages through the backend. PHP plugins run with full CMS privileges. The validator does not sandbox PHP or scan for malware. [Package format and trust](PACKAGES.md).

No pirated code, misleading compatibility, hidden paid dependencies, undisclosed tracking, credential collection, harassment or duplicate promotion. Maintainers may label, request corrections, close or remove entries under the [code of conduct](../CODE_OF_CONDUCT.md). Report vulnerabilities privately via [Security Advisories](https://github.com/WebCrew/Friends-SNCMS/security/advisories/new).

## Deutsch

Alle Erweiterungen werden zentral in den Discussions unter **Plugins** und **Themes** vorgestellt. Pro Paket ein Eintrag mit Autor, Quellcode-/Downloadlink, Lizenz, Preis/kostenlos, getesteter CMS-Version, API-Version, Anleitung und Support. Neue Versionen im vorhandenen Eintrag ergänzen. Der Eintrag ist keine Sicherheitsfreigabe. PHP-Plugins vor Aktivierung prüfen; keine automatische Installation aus dem Katalog.

Kommerzielle Erweiterungen sind willkommen. Wer damit Geld verdient, wird um eine freiwillige Unterstützung des kostenlosen Kerns gebeten; weder Spende noch Listungsgebühr sind Pflicht.
